# FNAF_MATLAB
A MATLAB version of a popular horror game Five Nights at Freddy’s by Scott Cawthon. The game utlise MATLAB built-in GUI functions to re-create the game's mechanics. 

## Features
- Re-creation of the first edition of Five Nights at Freddy’s. 
- Ability to choose the difficulty of the game.
- Using inheritance to implement the animatronics's behaviour.

## Known Issues
- At max difficulty, the game might stuck in a state where all the animatronics are at the final position.
- Jumpscare is still not properly implemented.

## Requirements
- MATALAB is required to run the game. 
- GUI toolbox is required.
